# Basic Weather App

## Project Overview

The Basic Weather App is a Python-based GUI application developed using Tkinter. It allows users to enter a city name and retrieve the current weather information using the Open-Meteo weather API.

## Features

- User-friendly graphical interface using Tkinter
- Accepts city name as input
- Retrieves current weather information
- Displays temperature in Celsius
- Displays feels-like temperature
- Displays humidity
- Displays wind speed
- Handles invalid city names
- Handles network errors
- No API key required

## Technologies Used

- Python
- Tkinter
- Requests
- Open-Meteo API
