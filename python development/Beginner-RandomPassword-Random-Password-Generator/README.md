# Random Password Generator

## Project Overview

The Random Password Generator is a Python-based GUI application that generates secure random passwords based on the length entered by the user.

## Features

- User-friendly graphical interface using Tkinter
- Allows the user to select password length
- Generates random passwords
- Includes uppercase and lowercase letters
- Includes numbers
- Includes special characters
- Validates password length
- Displays error messages for invalid input
- Provides a Copy Password feature

## Technologies Used

- Python
- Tkinter
- Random module
- String module
